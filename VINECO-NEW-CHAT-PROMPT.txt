============================================================
3. IMAGE RULES
============================================================

Khách cực kỳ quan tâm hình ảnh.

Khi khách ghi:
"full khung"
"phóng hình"
"không cắt"
"không chừa khoảng trắng"

phải xử lý đúng ý nghĩa từng trường hợp.

Ảnh sản phẩm/card:
- ảnh phải sử dụng tối đa diện tích khung
- không tạo padding trắng vô lý quanh ảnh
- không stretch ảnh
- nếu ảnh đã crop đúng trước đó thì ưu tiên width:100%, height:100%, object-fit:cover
- điều chỉnh object-position nếu cần giữ đầu chó/sản phẩm trong frame

Ảnh chứa thông tin/chữ, size guide, infographic:
- tuyệt đối không crop nội dung
- ưu tiên width:100%; height:auto
- tăng kích thước container thay vì dùng object-cover
- mục tiêu là đọc được chữ và thông số

Nếu khách yêu cầu full ảnh nhưng object-contain tạo khoảng trắng:
- không được chỉ đổi bừa sang object-cover
- xem lại aspect-ratio/container trước
- điều chỉnh chính khung theo tỷ lệ ảnh

Không scale ảnh bằng transform gây blur nếu có thể tránh.

============================================================
5. POWERSHELL PATCH RULE
============================================================

Khi tôi yêu cầu:
"sửa bằng PowerShell"
"viết lệnh sửa"

hãy đưa script PowerShell có thể copy chạy trực tiếp tại project root.

Project root thường là:

D:\Downloads\vineco-static-react-v2\vineco-static-react-v2

Script tốt phải:

1. kiểm tra file tồn tại
2. backup file trước khi sửa
3. sửa đúng file
4. validation sau patch
5. npm run build
6. nếu patch/build fail thì restore backup
7. báo rõ file nào đã sửa

QUAN TRỌNG:

Không dùng biến PowerShell:
$home

vì $HOME là biến read-only và PowerShell không phân biệt hoa thường.

Nên dùng:
$projectRoot
$source
$filePath
$pageCode

Không dùng regex quá phụ thuộc vào Tailwind class multiline nếu có giải pháp marker/nội dung ổn định hơn.

Nếu patch phức tạp:
PowerShell có thể tạo một Node .mjs tạm thời để patch JSX, sau đó PowerShell build/restore.

Không đặt script .ps1 vào project nếu Vite watcher gây EBUSY.
